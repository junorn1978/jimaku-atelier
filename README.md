# 字幕アトリエ

即時語音辨識＋翻譯的字幕顯示工具（瀏覽器網頁應用，可搭配 OBS 使用）。

本專案和 [ハムハム字幕アトリエ](https://junorn1978.github.io/durian-sub-workshop/) 是姊妹專案，兩邊互相移植：

- **從ハムハム字幕アトリエ移植過來**：原專案累積的開發經驗與功能，在這裡以重新整理過的架構實作。
- **移植回ハムハム字幕アトリエ**：在這裡新增的功能或修好的問題，若原專案也用得到，再移植回去。

## 使用

- 線上版：<https://junorn1978.github.io/jimaku-atelier/>
  - `launch_chrome_pages.bat` / `launch_edge_pages.bat`
