# 字幕アトリエ

リアルタイム音声認識と翻訳を利用した字幕表示ツールです。  
ブラウザ上で動作するWebアプリケーションで、OBSと組み合わせて使用できます。

本プロジェクトは、[ハムハム字幕アトリエ](https://junorn1978.github.io/durian-sub-workshop/) の姉妹プロジェクトです。  
両プロジェクト間で、機能や改善内容を相互に取り入れています。

- **ハムハム字幕アトリエからの移植**  
  元プロジェクトでこれまでに得た知見や実装をもとに、本プロジェクトでは構成を整理したうえで実装し直しています。

- **ハムハム字幕アトリエへの反映**  
  本プロジェクトで追加した機能や修正内容のうち、元プロジェクトでも利用できるものについては、ハムハム字幕アトリエ側にも反映しています。

## 使用方法

- オンライン版：<https://junorn1978.github.io/jimaku-atelier/>
  - `launch_chrome_pages.bat`
  - `launch_edge_pages.bat`
