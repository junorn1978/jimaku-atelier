URL 格式說明

支援以下寫法：

  • https://your-host.com/translate
  • your-host.com （自動補 https 與 /translate）
  • your-key://your-host.com （金鑰會以 X-API-Key header 送出）

伺服器會收到 POST /translate：

{
  "text": "こんにちは",
  "sourceLang": "ja",
  "targetLangs": ["en", "zh-TW"]
}

需回傳：

{ "translations": ["Hello", "你好"] }
