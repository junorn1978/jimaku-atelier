設定

URL の形式

次の形式で入力できます：

  • https://your-host.com/translate
  • your-host.com （https:// と /translate は自動で補完されます）
  • your-key://your-host.com （キーは X-API-Key ヘッダーで送信されます）

サーバーに次の POST /translate リクエストを送信します：

{
  "text": "こんにちは",
  "sourceLang": "ja",
  "targetLangs": ["en", "zh-TW"]
}

サーバーは次の形式でレスポンスを返します：

{ "translations": ["Hello", "你好"] }
